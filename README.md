## Use the maintained application

Download the current native GPUI application from the
[`alter-sendmer` release page](https://github.com/bruceblink/alter-sendmer/releases/latest).
The maintained project provides the AlterSendme send/receive workflow without the Tauri, React,
Node.js, or WebView runtime.

Before migrating, stop any transfer still running in this client. Existing received files remain
where they were saved. In-progress sessions and local interface preferences are not migrated; set
those preferences again after installing the GPUI application. See the
[full migration guide](https://github.com/bruceblink/alter-sendmer/blob/main/docs/MIGRATION.md) for
the current feature mapping and release details.

## Repository status

This repository is preserved as a read-only historical source archive. It will not receive new
features, bug fixes, dependency updates, releases, or security patches. New issues and pull requests
should be opened in the [maintained repository](https://github.com/bruceblink/alter-sendmer/issues).
